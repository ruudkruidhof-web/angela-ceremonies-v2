# Hero als filmopening: implementatieplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De homepage-hero van angelaceremonies.com vervangen door een filmische opening met een stille videoloop, titel linksonder, aftiteling rechtsonder en knoppen die niet meer wegvallen.

**Architecture:** Alles blijft in `src/pages/index.astro` (hero-markup, scoped CSS, bestaande GSAP-intro) en `src/components/Nav.astro` (knoppen). Content in `src/content/home.json`. De poster is een `astro:assets`-afbeelding en het LCP-element; de video staat erboven, laadt pas na `load` en vervalt bij reduced-motion of datasparen.

**Tech Stack:** Astro, GSAP (al aanwezig), Higgsfield (image-to-video), macOS `avconvert` voor H.264, Playwright via `~/lead-finder/node_modules` voor de controle.

**Afwijking van de spec:** geen WebM. Er is geen ffmpeg op deze machine; `avconvert` levert alleen MP4 (H.264), en dat speelt in elke huidige browser. De staande mobiele uitsnede gebeurt met `object-fit: cover` en `object-position` in plaats van een apart bijgesneden bestand; mobiel krijgt wel een kleiner bestand.

Werk op branch `hero-film` in `~/Klantmappen/Angela Ceremonies/site`.

- [ ] **Step 4: Script**

In `initHome` vervangt deze intro de regel `intro.from('.hero .he', ...)`:

```ts
      const intro = gsap.timeline({ defaults: { ease: 'power3.out' } });
      intro
        .set('.hero-bar', { scaleY: 1 })
        .to('.hero-bar', { scaleY: 0, duration: 0.9, ease: 'power3.inOut', delay: 0.1 })
        .from('.hero .he', { opacity: 0, y: 28, duration: 1, stagger: 0.12 }, '-=0.35');
```

En in de cleanup `gsap.set('.hero-bar', { clearProps: 'all' });` naast de bestaande `clearProps`. De parallax op `.hero-media` blijft.

Onder `initHome` een eigen functie voor de video, aangeroepen vanuit dezelfde `astro:page-load`-listener:

```ts
  let videoAbort: AbortController | undefined;

  function initHeroVideo() {
    videoAbort?.abort();
    videoAbort = new AbortController();
    const signal = videoAbort.signal;
    const video = document.querySelector<HTMLVideoElement>('[data-hero-video]');
    if (!video) return;
    const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    const saveData = (navigator as Navigator & { connection?: { saveData?: boolean } }).connection?.saveData;
    if (reduce || saveData) {
      video.remove();
      return;
    }
    video.addEventListener('playing', () => video.classList.add('is-playing'), { signal });
    const start = () => {
      video.preload = 'auto';
      video.load();
      video.play().catch(() => {});
    };
    if (document.readyState === 'complete') setTimeout(start, 200);
    else window.addEventListener('load', () => setTimeout(start, 200), { once: true, signal });
    const io = new IntersectionObserver(([entry]) => {
      if (!video.classList.contains('is-playing')) return;
      if (entry.isIntersecting) video.play().catch(() => {});
      else video.pause();
    });
    io.observe(video);
    signal.addEventListener('abort', () => io.disconnect());
  }

  document.addEventListener('astro:page-load', () => {
    initHome();
    initHeroVideo();
  });
```

en de oude regel `document.addEventListener('astro:page-load', initHome);` vervalt.
